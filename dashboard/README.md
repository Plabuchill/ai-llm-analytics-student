# แดชบอร์ดยอด บ้านสบาย ช๊อป

แดชบอร์ดยอดขายร้านออนไลน์ สร้างเป็น Claude Artifact ประเภท Dashboard

- แดชบอร์ด: https://claude.ai/artifact/AhPXBuJy22QegT71MxttxK
- `index.html` คือโค้ดหน้าแดชบอร์ด (สำเนาจาก Artifact) ใช้ได้เฉพาะภายใน Artifact เพราะต้องใช้ `dash` API, d3 และไฟล์ข้อมูลที่แนบไว้กับ Artifact

## ข้อมูล

| ชุดข้อมูล | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| `orders` | `data/orders.csv` (UTF-8 มี BOM) | คำสั่งซื้อรายแถว |
| `products` | `data/products.csv` | `unit_cost` สำหรับกำไรขั้นต้น จับคู่ด้วย `product_id` |

อัปโหลดไฟล์ใหม่ได้จากปุ่มด้านบนของแดชบอร์ด (เฉพาะผู้มีสิทธิ์แก้ไข) หน้าเว็บจะตรวจหัวคอลัมน์ก่อนแทนที่

## นิยาม

- ยอดขายสุทธิ = `qty × unit_price × (1 − discount_pct/100)` เฉพาะ `status = "จัดส่งสำเร็จ"` ไม่รวม `shipping_fee`
- AOV = ยอดขายสุทธิ ÷ จำนวนคำสั่งซื้อสำเร็จ
- อัตรายกเลิก = คำสั่งซื้อ "ยกเลิก" ÷ คำสั่งซื้อทั้งหมด
- กำไรขั้นต้น = ยอดขายสุทธิ − `qty × unit_cost`
- วันเมกะเซล = 10.10, 11.11, 12.12, 3.3, 6.6, 9.9

## หน้าในแดชบอร์ด

- **ภาพรวม**: KPI 4 ใบ, จำนวนแถวและสถานะ, ยอดรายเดือน, ยอดตามช่องทาง บริษัทขนส่ง จังหวัด ภูมิภาค และจังหวัดอันดับหนึ่งของแต่ละภูมิภาค
- **วันเมกะเซล**: สัดส่วนยอดขาย ยอดเฉลี่ยต่อวัน และ % กำไรขั้นต้น เทียบวันปกติ
- **บทสรุปผู้บริหาร**: รายงานหัวข้อละไม่เกิน 100 คำ ดาวน์โหลดเป็น PDF ที่เลือกคัดลอกข้อความได้ และคำสั่งสรุป 5 บรรทัดสำหรับ Claude (ส่งเฉพาะตัวเลขสรุปไม่เกิน 30 ค่า)

ตัวกรอง ภูมิภาค หมวดสินค้า ช่องทาง และช่วงวันที่ มีผลกับทุกหน้า
